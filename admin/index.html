Akses Owner

Dashboard ini belum terhubung ke autentikasi Supabase. Halaman ini belum memverifikasi identitas owner dan belum boleh digunakan untuk mengubah produk atau transaksi nyata.

Langkah aktivasi

1. Aktifkan login Google/email melalui Supabase Auth.

2. Verifikasi role owner di database dan backend.

3. Aktifkan kebijakan RLS agar hanya owner yang dapat mengelola produk.

4. Hubungkan dashboard ke database untuk menambah produk beserta foto.

Fitur yang akan diaktifkan

📦 Tambah produk dan foto
💰 Atur harga dan kategori
🧾 Kelola pesanan pelanggan
📲 Verifikasi top up dan pembayaran

Fitur pengelolaan akan diaktifkan setelah autentikasi dan izin database terpasang dengan benar.
